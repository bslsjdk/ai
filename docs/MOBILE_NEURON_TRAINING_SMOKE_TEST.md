# 手机神经元训练自测包

文件：`tests/fixtures/neuron_training_smoke_bundle.json`

这是一个**单文件导入包**，格式为 `aimeng-training-bundle/v1`，包含 96 条监督学习样本和训练参数。

## 在 Android 工作台中运行

1. 更新并安装包含“导入训练自测包，并自动开始训练”按钮的 AIMENG 构建。
2. 打开 **数据/保存** 页面。
3. 点击 **导入训练自测包，并自动开始训练**，选择 `neuron_training_smoke_bundle.json`。
4. 如果提示维度不同，先确认。应用会将旧工作区备份到内部存储，再切换为 2 输入、1 输出并开始训练。
5. 等训练完成，在 **训练任务** 页面查看训练/验证 MSE 和任务记录；到 **运行** 页面输入两个逗号分隔数值，例如 `0.25,-0.5`，网络应学习近似输出 `0.575`。
6. 到 **数据/保存** 页面导出训练结果 CSV 或完整工作区，保留实际测试结果。

## 任务是什么

- 输入：`x0`、`x1`，都在 `[-1, 1]`。
- 正确输出：`y = 0.7*x0 - 0.4*x1 + 0.2`。
- 训练参数：240 epochs，learning rate 0.01。
- 训练器：工作台现有 CPU/Adam 训练器；导入后自动开始，支持现有取消和保存逻辑。
- 目的：检查单文件导入、维度处理、训练、验证、持久化和结果导出链路。它不是语言模型基准，也不能证明模型具备自然语言理解能力。

## 本地检查数据包

在有 Python 3 的环境运行：

```sh
python3 scripts/test_neuron_training_bundle.py
```

该脚本检查 JSON 格式、维度、参数范围、有限数值、样本数量和目标公式。它不冒充 Android 端训练测试；优化器的真实收敛仍需在应用里观察验证 MSE。
