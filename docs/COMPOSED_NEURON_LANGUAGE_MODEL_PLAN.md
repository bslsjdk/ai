# 从独立神经元单元到语言模型：当前实现边界与 PK 路线

更新时间：2026-10-10

## 当前已经落地的内容

`scripts/train_composed_neuron_lm.py` 是一个从零训练、CPU 可运行的字符级语言模型，不加载 Qwen 权重。隐藏层中的每个神经元都作为独立记录保存，具有自己的 ID、输入权重、偏置、输出权重、启用状态和更新计数。训练时这些单元组合成前馈网络，对下一个字符做概率预测；模型权重和训练报告写入 `experiments/composed-neuron-lm/latest/`。

自动化工作流 `.github/workflows/composed-neuron-language-model.yml` 在 CPU runner 上训练三个固定随机种子，并自动把模型检查点、逐轮日志和汇总 JSON 提交回实验分支。

## 不能混淆的三种系统

1. **预训练基线**：Qwen2.5 是外部已有的 Transformer，用于测量目前通用语言模型的基线。
2. **此前控制实验**：GridWorld 的小型 Q 网络验证学习机制，不是语言模型。
3. **当前自建模型**：显式神经元单元组成的字符级预测网络，从随机初始化开始学习一个合成文本语料。它是“独立单元组合成网络并进行语言建模”的最小可执行原型，但能力远小于通用 LLM。

## 目前还没实现的部分

- 目前连接是固定的一层全连接输入到隐藏单元、隐藏单元到输出层，不是动态稀疏图。
- 还没有依据验证贡献自动增删连接、复制/合并单元、分层路由或专家协作。
- 语料是合成的算术格式文本，不是高质量大规模自然语言语料；结果不能与 Qwen 的问答准确率直接横向比较。
- 字符级、固定窗口模型不能建模任意长度的上下文，也不等于完整的推理语言模型。

## 后续阶段与通过条件

### 阶段 A：确认基础闭环
固定语料哈希、三组随机种子、独立保留测试集；报告参数数、训练耗时、验证交叉熵、下一个字符准确率、基线交叉熵、模型文件和原始日志。首先要求模型稳定优于 unigram 基线。

### 阶段 B：神经元组合机制消融
在参数量和训练预算匹配下，比较：
- 固定全连接隐藏单元；
- 稀疏连接的独立单元池；
- 按验证集贡献选择/屏蔽单元；
- 允许复制、变异、剪枝并能回滚的动态拓扑。

同一数据切分、相同种子集合，记录准确度、交叉熵、推理延迟、参数数、实际峰值内存。任何动态结构只有在独立测试集稳定获益时才保留。

### 阶段 C：从字符建模走向真实文本任务
接入可复现的分词器与公开许可语料，增加中文/英文、指令遵循、组合泛化、长程依赖和多步推理任务。必须同时保留相同数据、量化精度、上下文预算、训练 FLOPs/时间等公平比较条件。

### 阶段 D：与预训练语言模型正面对决
将自建模型与公开基线放在共同任务集上评测，分开报告正确率、校准/格式遵循、长上下文、泛化、速度、峰值内存和训练成本。只有同一任务、同一评分规则和可复现的多次运行结果才算 PK；不拿合成字符预测分数冒充通用推理胜利。

## 资源与诚实性约束

当前阶段在云端 CPU 上训练，参数和批量有上限。未来若移植到手机，仍必须遵守项目约定的整个进程运行时内存低于 4 GiB 的硬约束。当前报告会明确写出数据与架构限制，不把一个能拟合字符模式的小模型宣传成通用智能。


## 已验证实验：固定稀疏 vs. 动态重组（2026-10-10）

脚本：`scripts/compare_sparse_dense_neuron_lm.py`、`scripts/test_dynamic_sparse_neuron_lm.py`。工作流分别为 `.github/workflows/sparse-dense-neuron-lm-ablation.yml` 与 `.github/workflows/dynamic-sparse-neuron-lm.yml`。

在同一合成字符语料、3 个随机种子和 24 轮训练下，参数量几乎完全匹配（动态稀疏 1,570；全连接 1,569）：

| 结构 | 平均验证字符准确率 | 平均验证损失 | 平均训练时间 |
|---|---:|---:|---:|
| 固定随机稀疏连接 | 50.63% | 2.094 | 1.87 s |
| 动态重组，12.5%/轮 | 70.63% | 1.297 | 2.03 s |
| 动态重组，25%/轮 | 67.92% | 1.401 | 1.96 s |
| 动态重组，37.5%/轮 | 58.22% | 1.701 | 1.98 s |
| 参数匹配全连接 | 72.37% | 1.193 | 1.25 s |

完整数据：`experiments/dynamic-sparse-neuron-lm/latest/summary.json`。动态模型会按神经元 ID 保存输入连接索引、输出 token 索引、权重范数及单元消融造成的验证损失变化，可用于检查哪些单元实际有贡献。

**解释边界：** 动态重组明显优于固定随机稀疏，但目前仍比全连接低约 1.74 个百分点，并且训练更慢。这只是小型合成字符任务上的结构实验，不代表通用语言推理能力，也不证明动态稀疏在其他任务上必胜。当前下一步应把同样的可审计单元拓扑和贡献分析迁移到真实文本/组合泛化任务，再决定是否值得扩大模型。


## 真实聊天模型基线（2026-10-10）

工作流 `.github/workflows/llm-pk-benchmark.yml` 已在 CPU 的 `llama.cpp` 推理后端运行同一套 90 道诊断题，使用固定 Q4_K_M 量化模型与确定性解码。原始逐题输出已保存到 `experiments/llm-pk/latest/`。

| 模型/模式 | 总正确 | 准确率 | 平均单题耗时 |
|---|---:|---:|---:|
| Qwen2.5-0.5B-Instruct Q4_K_M，单次回答 | 54/90 | 60.00% | 0.317 s |
| Qwen2.5-0.5B-Instruct Q4_K_M，二次验证 | 51/90 | 56.67% | 0.743 s |
| Qwen2.5-1.5B-Instruct Q4_K_M，单次回答 | 66/90 | 73.33% | 0.687 s |

1.5B 模型分类准确率：算术 95.83%（23/24）、上下文回忆 100%（16/16）、演绎 62.5%（10/16）、指令格式 60%（6/10）、数列 91.67%（11/12）、状态更新 0%（0/12）。状态更新类别所有基线都未答对，应该保留为一个明确的失败点，后续检查提示设计与模型能力，而不是把它藏掉。

**公平性边界：** 这组结果是现成 Qwen 模型的诊断基线，不是自建神经元模型的 PK 成绩。当前自建模型只在合成字符预测任务上评测；在把自建模型接入同一问答接口并使用完全相同的 90 道题之前，不能直接比较两边的准确率。该题集是本项目生成的诊断套件，不是公开排行榜，也不足以证明通用智能。


## 长期目标：以更低参数预算反超 9B 级语言模型

目标不是在合成题上刷一个好看的分数，而是逐步训练出从零开始、由可检查的神经元单元构成的语言模型，并最终在明确的共同测试集上超过约 9B 参数级基线，同时显著减少可训练参数和推理资源。此目标是长期研究目标，当前原型距离目标还很远。

### 阶段路线与晋级条件

1. **真实文本闭环**：用公开领域文本从随机初始化训练循环神经元网络；保存数据哈希、参数量、训练预算、验证损失、bits/character、生成样例和单元消融。
2. **结构消融**：在同一数据切分和近似参数预算下比较普通全连接、固定稀疏、动态重组和循环神经元。多个随机种子报告均值与波动，记录速度及内存；不因单次胜出就宣布结构优越。
3. **扩展语料与分词**：从单书字符预测推进到多来源、许可清晰的文本；对比字符、字节与子词表示，避免把字符级困惑度直接当作聊天能力。
4. **语言能力测试**：训练指令格式、事实检索、组合泛化、多步状态更新与长上下文测试。训练、验证、测试数据必须隔离，并保留逐题错误。
5. **公平的 9B PK**：固定测试集、提示词、解码参数、量化精度与硬件；同时比较任务质量、校准、上下文长度、延迟、峰值 RAM、模型文件大小、训练计算量和能耗。对比必须明确“参数量”究竟是总参数、激活参数还是每 token 实际执行参数，不能把不同定义混为一谈。
6. **移动端约束**：任何面向手机的推理方案都必须满足项目的运行时 RAM 小于 4 GB 硬约束；云端训练成绩不能代替设备实测。

### 当前基线位置

截至 2026-10-10，动态稀疏重组只在小型合成字符预测任务上优于固定随机稀疏网络，但略逊于参数量匹配的全连接模型。现成 Qwen 的 90 题诊断结果是外部参考，不能和自建模型的字符级准确率直接横向比较。下一步先建立真实文本循环神经元 LM 的可复现基线，再做同预算结构消融；不会提前宣称已经反超任何 9B 模型。


## 真实文本循环网络：验证集选 checkpoint 的结果（2026-10-10）

在 Project Gutenberg 公版《Alice's Adventures in Wonderland》上，训练了 3 个随机种子的 64 单元 vanilla RNN，约 13,964 个参数。当前正式评估协议按原文顺序切分为 85% 训练、5% 验证和最后 10% 最终测试；每轮仅查看验证集来选择 checkpoint，最终测试集只在训练结束后用于报告和单元消融。

- 平均最终测试交叉熵：**1.716**（unigram 基线为 **3.172**）
- 平均 bits/character：**2.475**
- 平均 next-character 准确率：**51.59%**
- 平均训练耗时：每个 seed 约 **68.0 秒**
- 平均单神经元消融测试损失增量约 **0.148**
- 三个 seed 选中的最佳验证轮数分别为 **29、25、26**，平均约 **26.7** 轮

相较旧的 90%/10% 报告，测试分数略有下降是预期可能出现的变化：数据切分与 checkpoint 选择协议更严格，不能把两个数值直接当作同一测试集上的回归。模型生成仍然不连贯，所以这些结果只说明它学到了文本中的局部字符统计结构，不代表理解、问答或推理能力。

结果文件：`experiments/recurrent-neuron-lm/latest/summary.json`。模型导出后新增了独立终端推理脚本；工作流已通过 round-trip 检查，导出 JSON 的独立推理结果与训练时相同提示词、随机种子下的生成前缀一致。

## 参数预算对照：循环状态 vs. 固定上下文（2026-10-10）

实验文件：`experiments/recurrent-vs-fixed-context/latest/summary.json`。同一份《爱丽丝梦游仙境》文本、同一数据哈希、三个随机种子；固定上下文网络训练的 next-character 目标数与早期 8 轮循环网络 smoke test 对齐，但批大小和更新策略不同，因此训练时间只作为参考。

| 架构 | 参数量 | 平均测试字符准确率 | 平均测试交叉熵 |
|---|---:|---:|---:|
| 固定上下文，2 个隐藏单元 | 9,958 | 27.63% | 2.657 |
| 固定上下文，3 个隐藏单元 | 14,899 | 32.14% | 2.515 |
| 循环网络，64 个隐藏单元（早期 8 轮结果） | 13,964 | 49.24% | 1.805 |

该结果支持继续研究循环状态在小参数预算下的作用，但不是严格等计算量的最终排名：循环模型的更新方式、批大小、每轮样本重复情况与固定上下文网络不同。30 轮循环模型的旧结果约为 52.34% 字符准确率，但训练预算更大，不能直接与 8 轮固定上下文网络当成同预算胜负。

### 评估协议改进

后续循环网络实验改为按原文顺序切分 **85% 训练 / 5% 验证 / 10% 最终测试**。验证集只用于选择最低验证损失的 checkpoint，最终测试集只在训练结束、恢复最佳 checkpoint 后用于汇报和单元消融。历史报告使用的 90%/10% 单次切分会保留作历史结果，不与新协议的分数混为同一条曲线。该更改旨在避免反复查看测试指标后再调整训练策略造成评估污染。


## 终端推理入口

训练导出的 `model.json` 可通过 `scripts/run_recurrent_neuron_lm.py` 独立加载，不必重新训练。示例：

```bash
python scripts/run_recurrent_neuron_lm.py \
  --model experiments/recurrent-neuron-lm/latest/seed-20261010/model.json \
  --prompt "Alice " --max-chars 200 --temperature 0.8 --seed 7
```

可加 `--output generated.txt` 把结果写入文本文件。训练工作流会对每个 seed 的导出 checkpoint 执行一次推理 smoke test，确认权重方向、输出概率和提示词前缀正确。此入口是 Python/NumPy 参考运行器；它不是 Android 原生实现，也没有声称满足手机运行时内存约束。移动端部署仍需单独实现并测量。


## 外部审查后新增的真实文本基线（2026-10-10）

审查指出：2/3 隐藏单元的固定上下文网络虽然参数量接近 64 单元 RNN，但隐藏计算容量明显不足，不能作为有力的结构对照。该批次不再把早期 width-2/3 结果作为“循环结构获胜”的证据。

新增脚本：`scripts/run_real_text_baselines.py`；工作流：`.github/workflows/real-text-ngram-fixed-window-baselines.yml`。

- 字符 2/3/4/5-gram，采用递归 Dirichlet 插值平滑，unigram 基分布使用加性平滑；在最终测试段评估。
- 固定窗口神经网络：16 字符上下文、64 个隐藏神经元，三个随机种子；按验证损失选 checkpoint，只在最后评估一次测试集。
- 保存逐轮训练/验证曲线、参数量、测试损失、bits/character、准确率、耗时和数据 SHA-256。
- 固定窗口网络训练目标数、批大小与 RNN 的 BPTT 更新方式不同，因此结果将明确列出训练预算；在没有 FLOPs 或等价操作数测量之前，不会宣称计算量严格匹配。

判定规则：如果 n-gram 在测试集上接近或优于 RNN，说明当前 RNN 学到的结构可能仍主要是局部字符统计；如果固定窗口模型明显改善，则旧的 2/3 单元对照确实过弱。无论结果如何，都先报告均值、样本标准差和曲线，再决定是否进行无循环连接消融。


### 审查中发现并修复的基准管线问题

复核第一份 n-gram / 固定窗口产物时，发现基准工作流中的换行查找字符串被多转义了一次，导致 Gutenberg 许可说明没有被剥除；因此那份报告的数据哈希与 RNN 训练文本不一致，不能拿来作直接比较。另发现报告尾部写入了字面量 `\\n`，使文件不是严格有效的 JSON。两项问题都已修复，并要求最新工作流重新生成产物。旧哈希报告应视为作废，不引用其中的分数作结论。


## 真实文本基线与去循环连接消融（2026-10-10）

外部审查建议补充强 n-gram 基线、固定窗口网络，以及去循环连接消融。已在同一份《爱丽丝梦游仙境》文本上完成三组种子实验，并修正评估上下文：RNN 每个 64 字符序列片段从零状态开始，固定窗口和 n-gram 现在也在同一目标位置将可用上下文限制在对应片段内，避免它们额外读取片段起点之前的字符。

所有有效报告的规范化文本 SHA-256 均为 `e3917589f48b4e9f4b731a6b7e127cf9ddd6e1b3819c78be02a2702ee73bfdb1`，按原文顺序切分为训练 85%（122,913 字符）、验证 5%（7,230 字符）、测试 10%（14,461 字符）；按与 RNN 相同的 64 字符分块规则，最终测试计分 14,400 个 next-character 目标。RNN 与去循环消融均只用验证集选择 checkpoint。

| 模型 | 参数/训练说明 | 测试交叉熵（越低越好） | bits/字符 | 字符准确率 |
|---|---|---:|---:|---:|
| 2-gram | 统计模型，验证集选择平滑参数 | 2.42094 | 3.49268 | 30.53% |
| 3-gram | 同上 | 1.91747 | 2.76632 | 43.86% |
| 4-gram | 同上 | 1.68129 | 2.42559 | 51.88% |
| 5-gram | 同上 | 1.63569 | 2.35980 | 54.24% |
| 固定窗口网络 | 16 字符上下文、64 隐藏单元、82,828 参数；3 seeds | 1.87076 ± 0.00391 | 2.69894 ± 0.00565 | 47.56% ± 0.21% |
| 64 单元循环 RNN | 13,964 参数；3 seeds | 1.71564 ± 0.00759 | 2.47515 ± 0.01095 | 51.59% ± 0.11% |
| 去循环连接消融 | 与 RNN 同样的 64 单元形状；将循环矩阵 Wh 固定为零，不更新；总参数计数含冻结矩阵为 13,964，可训练参数为 9,868；3 seeds | 2.41744 ± 0.00056 | 3.48764 ± 0.00082 | 30.40% ± 0.15% |

神经网络结果为三个随机种子的均值 ± 样本标准差。loss 是按目标字符平均的自然对数交叉熵；bits/字符 = loss / ln(2)。n-gram 使用递归 Dirichlet 插值平滑，平滑参数从验证集候选网格中选择，未用测试集调参。

### 当前能得出的结论

- 去循环版本的测试损失（2.41744）与 2-gram 基线（2.42094）非常接近，准确率也接近。这符合机制预期：禁用循环状态后，每个位置只根据当前输入字符预测下一个字符，无法保留更早字符的信息。
- 当前 RNN 相对去循环版本的测试交叉熵明显更低（1.71564 vs. 2.41744），字符准确率更高（51.59% vs. 30.40%）。这是支持“循环状态对这项单书字符预测任务有贡献”的直接消融证据，但不是通用语言能力或推理能力证明。
- 5-gram 仍然优于当前 RNN，说明局部字符统计是很强的基线。不能因为 RNN 赢过去循环消融，就声称 RNN 已超过传统语言模型。
- 固定窗口网络参数约为 RNN 的 5.93 倍，却在此训练配置下落后于 RNN。固定窗口的训练预算尚未与 RNN 按近似 MAC 数匹配；正在运行另一组约等训练 MAC 的固定窗口实验，结果完成后再补充对照。
- 三个种子只能提供初步的运行波动估计。所有结论限定于这本书的字符预测；不外推到聊天、事实问答或多步推理。
