# AIMENG 知识蒸馏实验（简化说明）

手机端不加载 Qwen/TinyLlama 老师模型。老师只在电脑或 Kaggle 上生成知识文件；手机导入该文件，再训练约 8K 参数的学生网络。这样不会把老师模型塞进手机 4GB 运行内存预算。

## 1. 在电脑 / Kaggle 生成老师知识文件

准备一个 UTF-8 的中文文本文件，例如 `corpus.txt`。建议使用多篇不同的短文，验证集会自动取文本末尾约 10% 的上下文。

安装依赖：

```bash
pip install torch transformers
```

生成数据集：

```bash
python tools/generate_aimeng_distillation.py \
  --model Qwen/Qwen2.5-0.5B-Instruct \
  --text-file corpus.txt \
  --output aimeng_distillation.jsonl \
  --max-examples 5000 \
  --top-k 10
```

首次运行需要下载老师模型。可以在 Kaggle Notebook 里先上传脚本和文本文件，运行安装命令，再执行同样的 Python 命令。完成后把 `aimeng_distillation.jsonl` 下载到手机。

如果只是验证管线，也可以不传 `--text-file`，脚本会使用内置短故事重复生成一个很小的 smoke-test 数据集；这种结果只能验证流程，不能用来判断泛化能力。

## 2. 在 AIMENG 手机应用里训练

1. 打开“更多实验与模型管理” → “中文学习与知识蒸馏实验”。
2. 点“知识蒸馏：导入老师知识文件”，选择 `aimeng_distillation.jsonl`。
3. 等待训练和独立验证结束。报告会显示验证 KL、老师 Top-3 覆盖率和更新数量。
4. 点“导出训练检查点到手机文件夹”，把学生检查点保存到“下载”或你选择的文件夹。

## 3. 结果应该怎么看

- **验证 KL**：越低表示学生对老师提供的字符分布拟合得越好。
- **老师 Top-3 覆盖率**：学生自己的前三名预测与老师前三名候选的重合率。它不是通用语言能力百分比。
- **基线对照**：至少用同一数据集比较“随机初始化学生”和“蒸馏后的学生”，并用未参与训练的 eval 样本。
- **边界**：当前映射只采用老师 tokenizer 中能精确解码成一个、且存在于学生 200 字符词表内的 token。多字符子词概率不会被假拆分；数据集会记录映射概率质量。当前实验验证的是受限字符分布上的蒸馏，不等于把老师的全部知识压进学生。

## 4. 资源与安全

- 老师推理在电脑/Kaggle 运行，不在手机执行。
- 手机训练按样本顺序执行，不保留整段反向传播图。
- 应用在 PSS 达到 2.5 GiB 时停止蒸馏并尝试保存检查点；整体运行时仍应遵守项目的 4 GiB RAM 硬限制。
